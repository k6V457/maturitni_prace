\subsection{Vstup}
Tato kapitola se zabývá návrhem vstupních obvodů pro model robota. Hlavními částmi je Power Delivary pomocí USB C, ochrana vstupů a převod dat z USB na UART a JTAG používaných pro programování a debugging ESP32.\\
