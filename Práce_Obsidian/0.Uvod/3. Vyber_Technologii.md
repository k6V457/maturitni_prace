Nejprve bylo pro tuto práci potřeba vybrat programy, ve kterých bude možno pracovat na této práci. Co je potřeba? Nákresy od ruky, Od toho slouží Xournal++. Dále jsou potřeba schémata a návrh DPS, od toho slouží KiCAD. Pro ověření schémat byl zvolen program SimulIDE. Pro programování bylo použito VS Code s pluginy pro vývoj ESP32 PlatformIO a ESP-IDF. Jako poznámkový blok byl zvolen program Obsidian a pro psaní samotné práce bylo opět použito prostředí VS Code, tentokrát s pluginy pro editaci TEX souborů a zobrazení PDF.
